# SteamRentLK1 - Система аренды Steam аккаунтов

Автоматизированная система для аренды Steam аккаунтов через платформу FunPay с интеграцией Telegram бота.

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r req.txt
```

### 2. Настройка конфигурации

Скопируйте `.env.example` в `.env` и заполните реальными значениями:

```bash
cp .env.example .env
```

`config.py` читает эти значения через `python-dotenv` — сам файл `config.py` секретов не содержит и безопасен для коммита.

### 3. Steam Guard аккаунты

Файлы мобильного аутентификатора (`.maFile`) для каждого сдаваемого в аренду Steam-аккаунта должны лежать в `botHandler/accounts/` (папка в `.gitignore`, в репозитории её нет — создайте сами и положите туда свои `.maFile`).

### 4. Запуск

```bash
python main.py
```

## ⚙️ Конфигурация

### Обязательные параметры:

- `FUNPAY_GOLDEN_KEY` - API ключ FunPay
- `BOT_TOKEN` - Токен Telegram бота
- `ADMIN_ID` - ID администратора в Telegram
- `SECRET_PHRASE` - Секретная фраза для доступа к боту

### Опциональные параметры:

- `PROXY_URL` - URL прокси сервера
- `PROXY_LOGIN` - Логин для прокси
- `PROXY_PASSWORD` - Пароль для прокси

## 🔧 Основные возможности

- **Автоматическая аренда** Steam аккаунтов через FunPay
- **Безопасность**: автоматическая смена паролей по истечении аренды
- **Telegram интерфейс** для удобного управления
- **Система уведомлений** о новых заказах и истечении аренды
- **Автоматическое продление** аренды при получении отзывов
- **Поддержка прокси** для обхода блокировок

## 📁 Структура проекта

```
├── botHandler/          # Telegram бот
├── funpayHandler/       # Интеграция с FunPay
├── steamHandler/        # Управление Steam аккаунтами
├── databaseHandler/     # Работа с базой данных
├── FunPayAPI/          # API для FunPay
├── config.py           # Конфигурация
└── main.py             # Точка входа
```

## 🛡️ Безопасность

- Все чувствительные данные должны храниться в переменных окружения
- Не коммитьте файл `config.py` с реальными ключами
- Используйте сильные пароли для Steam аккаунтов
- Регулярно обновляйте API ключи

## 📝 Логирование

Система ведет подробные логи в файле `application.log` и выводит их в консоль.

## ⚠️ Важные замечания

1. Убедитесь, что у вас есть права на изменение паролей Steam аккаунтов
2. Настройте прокси, если FunPay заблокирован в вашем регионе
3. Регулярно проверяйте логи на наличие ошибок
4. Создайте резервные копии базы данных

## 🆘 Поддержка

При возникновении проблем проверьте:
1. Правильность настройки конфигурации
2. Логи в файле `application.log`
3. Подключение к интернету и FunPay
4. Корректность API ключей
